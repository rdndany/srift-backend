# SolRift

A browser voxel sandbox adventure that grows through MMO-style expansions (new bosses, instances and dungeons), with Solana-powered payments and ownership (planned, devnet first).
See [`docs/PLAN.md`](docs/PLAN.md) for the full roadmap and [`PROJECT_OVERVIEW.md`](PROJECT_OVERVIEW.md) for a complete, agent-oriented description of what is built and how it fits together.

## Quick start

```bash
npm install
npm run dev          # game server (:8787) + Next.js client (http://localhost:3000)
npm test             # unit + integration tests (vitest)
npm run typecheck
npm run build        # production build of the Next.js app
npm run loadtest      # 100 simulated players against a local server (--clients N --seconds S)
npm run test:e2e     # headless browser smoke + visual scenarios (needs: npx playwright install chromium)
```

The client works without the server (single-player; edits persist in IndexedDB). When the server is up, the HUD shows the connection and ping.
Set `NEXT_PUBLIC_SERVER_URL` (e.g. `wss://play.example.com`) to point the client at another server.
To put it online (page on Vercel, server on a droplet, Caddy for https), see [`docs/DEPLOY.md`](docs/DEPLOY.md) and the files in `deploy/`.

## Controls

| Input | Action |
|---|---|
| WASD | Move |
| Space | Jump (double-tap to toggle fly in creative) |
| Shift | Sneak / fly down / get out of bed |
| Double-tap W or Ctrl | Sprint |
| Left click (hold) | Mine (speed depends on the tool; creative breaks instantly) / attack mobs |
| Right click | Place block or torch, till soil with a hoe, plant seeds / open crafting table, furnace, chest / hold to eat / hold to raise a shield / go to sleep in a bed / open and close doors, trapdoors and gates / with the map in hand: bring it close to read it, again to put it away (the wheel zooms it) |
| F | Swap the shield between your hand and the off hand |
| E | Inventory (creative palette in creative mode); Esc or E closes |
| Q / Ctrl+Q | Drop one / the whole stack |
| F4 | Toggle survival / creative |
| 1-9 / mouse wheel | Select hotbar slot |
| F5 or V | Camera: first person, third person from behind, third person from the front |
| F3 | Debug overlay |
| M | Toggle music |
| J | Show or hide the minimap in the corner |
| `[` / `]` | Render distance |
| R | Respawn |
| Z / X / C / G | Class abilities 1 to 4 (characters with a class; the bar at the bottom right also takes a click or a tap) |
| K | Class sheet: your class, its level, stats and abilities |

URL parameters: `?seed=123` selects a world seed; `?mode=creative` starts in creative; `?nomobs` turns off natural mob spawning; `?debug` exposes `window.__solrift` (teleport, set time, edit blocks, spawn mobs, plant, use items) for automated tests.

Graphics options (all URL parameters): `?noshadows` turns off sun and moon shadows; `?shadows=4096` raises the shadow map size (default 2048); `?noaa` turns off antialiasing; `?nohalos` turns off the glow around torches; `?noautoquality` stops the game lowering shadows and resolution by itself when the frame rate stays low (it never does this under `?debug`).

## Layout

- `packages/shared`: block registry, noise, world generation, lighting, physics, raycast, protocol (deterministic; used by client, server and tests)
- `apps/web`: Next.js (App Router, React 19) client. `src/components` is the React shell; `src/game` is the engine (Three.js, workers, greedy mesher, audio, particles)
- `apps/server`: Node WebSocket server (hello/ping now; authoritative simulation arrives in Phase 3)
- `scripts`: headless E2E runner (Playwright)

## Engine highlights

- Infinite seeded terrain: 7 biomes, caves, ores, trees; generated in a Web Worker pool
- Greedy meshing with per-vertex ambient occlusion and smooth lighting
- Flood-fill sky light and block light (glowstone); time of day is a shader uniform, so no remeshing at dusk
- Procedural textures and sound effects (no external assets)
- Break particles, hit/break/place/footstep/splash sounds
- Day/night cycle with sun, moon and stars; fog; underwater tint
- Survival rules in packages/shared (pure, tested logic that the Phase 3 server will reuse): mining times, crafting recipes, menus, furnace, vitals
- Procedural item sprites (tools per material, food, ingots) generated into the same atlas as block textures
- Mobs: 18 kinds (pig, cow, sheep, chicken, rabbit, squid, bat, zombie, skeleton, creeper, spider, cave spider, slime, enderman, husk, stray, drowned) with A* voxel pathfinding, melee/knockback, loot, skeleton arrows with gravity lead, creeper explosions that carve the terrain. Hostiles spawn in darkness (torches keep an area safe), passives on grass by day; all logic is pure and lives in packages/shared
- Non-cube blocks: torches (floor and wall, light 14, pop off when unsupported), flowers and tall grass (replaceable, need soil), wheat crops (4 stages, hoe + farmland + seeds, random growth) meshed as crossed planes or thin posts
- First-person hand: real 3D blocks, extruded pixel-sprite items, bob, swing and equip animations

## Status

- Phase 0: monorepo, tooling, server smoke test (done)
- Phase 1: voxel engine core (done): see the list above. Not yet: LOD, occlusion culling
- Phase 2a (done): items, 36-slot inventory with original click semantics (split, merge, shift-click), 2x2/3x3 crafting, furnace smelting and fuel, chests, tools with harvest levels and durability, block drops and item entities, health/hunger/saturation, fall and drowning damage, death and respawn, creative mode
- Phase 2b (done): five mobs with AI, pathfinding and loot, torches, flowers, wheat farming, bread, hoes, first-person hand
- Phase 2c (done): bows and arrows (draw, zoom, damage by power, durability, flint/string/arrow recipes), saplings that grow into trees, weather (rain and thunderstorms that dim the sky, shorten fog and stop at roofs, with rain and thunder audio), procedural music, birdsong and cave ambience, and mob and weather persistence. 
- Phase 3.1 (done): versioned save format with migrations (the old localStorage saves upgrade automatically), compressed chunks in IndexedDB, and world export/import as .solrift files from the start/pause screen. 
- Phase 3.2 (done): Sign-In With Solana. The server issues a one-time challenge, the wallet signs it, and the server verifies the signature and sets an HttpOnly session cookie. Players get a public display name and the wallet address is never shown to others. Env vars: `AUTH_ORIGINS`, `DATABASE_PATH`, `COOKIE_SECURE`, `COOKIE_DOMAIN`, `TRUST_PROXY`, `SERVER_ORIGIN`, `NEXT_PUBLIC_SERVER_URL`.
- Phase 3.3 (done): cloud saves for signed-in players. The browser copy stays the working copy and uploads only the chunks edited since the last sync. Every upload names the cloud revision it is based on, so a stale device gets a conflict dialog instead of overwriting newer progress. A write lease stops two tabs or devices editing one world, overwrites take an automatic backup, and backups can be restored from the start screen.
- Tests: 999 unit tests plus thirty headless E2E suites (smoke, scenarios, gameplay, mobs, plants, bow, weather, saves, auth, cloud, online, xp, armor, view, home, world, nature, recipes, shield, bed, building, dyes, villages, trading, enchanting, anvil, fire, worlds, vehicles, redstone). `E2E_ONLY=cloud npm run test:e2e` runs one suite.
- Phase 3.4 (done): the game simulation is a pure `GameSession` in `packages/shared` (no DOM, audio or rendering). The browser is a client that sends it validated input frames and commands over a loopback link and plays back its events.
- Phase 3.5 (done): server-authoritative multiplayer. Start the server (`npm run dev:server`, or `npm run dev` for server and web together), then open the game at `/play` or `/play/<your name>` (the old `?online&name=<your name>` still works and is shown as `/play/<name>`; or click Play online); `?server=ws://host:port` picks a server and T opens chat. The server runs the same simulation as single-player while clients predict their own movement, and it persists the world and signed-in players. Set `CHEATS=1` on a private server to allow `/time`, `/weather`, `/gamemode` and `/tp`.
- Phase 3.6 (done): hardening. Players earn suspicion points for flooding, replaying or abusing commands and are warned, then kicked; sockets are limited per address and checked with a heartbeat; slow clients get back-pressure; snapshots are compressed. `npm run loadtest` (`--clients 100 --seconds 30`) runs simulated players against a server and checks tick time, bandwidth and kicks. Fuzz tests check that items are never duplicated or lost. See [docs/ACCOUNTS_AND_SAVES.md](docs/ACCOUNTS_AND_SAVES.md).
- Crowds (done): one server takes 120 players by default (`MAX_PLAYERS`); 100 players standing in one spot cost the server about 6 ms of its 50 ms tick, because each player is serialised once per tick for everybody. The browser draws only the 20 nearest players as full figures and the rest as simple blocks (about 200 draw calls with 100 players in view), and the realm page shows "Online 37 / 120". `scripts/crowd.mjs` (part of `npm run test:e2e`) runs a real browser against 99 bots.
- Experience and levels (done): killing mobs, mining coal and diamond ore with the right tool, and taking smelted items out of a furnace (and trades with villagers) give you experience straight away, with a floating "+N XP". The level curve is the original's (7 points for the first level, rising to 112 per level at 30), the bar and level number sit above the hotbar, dying costs a quarter of your experience points (you can lose a level) and wears down what you have equipped, but you keep every item and nothing is dropped, and the level is saved in single-player, cloud saves and on the server. Online, the server owns experience; on a private server with `CHEATS=1`, `/xp 50` or `/xp 10L` grants it. Enchanting and anvils (which would spend levels) are not built yet.
- Armor (done): leather, gold, iron and diamond helmets, chestplates, leggings and boots (crafted, 16 pieces) with the original defense points, toughness and durability. Right-click a piece to wear it, or open the inventory with E: four armor slots sit beside a character that wears what you wear (it follows the mouse). Armor shows as a row of icons above the hearts, reduces damage from mobs, arrows and explosions, wears down with each hit (and a fifth of its life when you die), is saved, and other players see it online. Cows drop leather. F5 (or V) shows your own character from behind and from the front, wearing the armor and holding what is in your hand (other players hold their items too). Chainmail, enchanting and dyeing are not built.
- Shield (done): six planks round an iron ingot make a shield (336 durability). Hold right-click to raise it, from the hand or from the new off-hand slot (beside the character on the inventory screen, left of the hotbar when filled); F swaps the shield between hand and off hand. After a quarter of a second it stops damage from the front 180 degrees (BLOCK floats up in the middle of the view; a hit that lands in the fifth of a second after the guard comes up is a PARRY: it costs the shield no wear, and the sound and the word are brighter, so lowering and raising it again at the right moment is a skill): melee hits (with no knockback), arrows and explosions (the blast still pushes you), but not what comes from behind or the side. A blocked hit of 3 or more costs the shield 1 + the damage in durability and it breaks at 0, with a thud and a ring for each block. You cannot sprint with it up. If your hand has something to do (eating, a bow with arrows, a block to place, a bucket, armor) that comes first. Shown in first person (resting low at the side, rising to the middle), on your own character in third person and on other players online; it is saved, loses a fifth of its durability on death and is kept by the server. The off hand holds only shields, and there are no banners or axes that disable shields.
- Bed (done): three wool over three planks make a bed. It is two blocks, a foot where you click and a head the way you face, 9/16 of a block tall, so you walk up onto it. Right-click it to use it: that always makes it your respawn point (`Respawn point set`); at night (dusk to just before dawn) or in a thunderstorm you also lie down, unless a hostile mob is within 8 blocks (5 up or down). While asleep the screen fades to black, you cannot move or act, and your figure lies on the bed, also for other players. Shift, the Leave Bed button, being hurt, the bed being broken or morning wake you, and you stand beside the bed. In single player the night is skipped (and the weather clears) after five seconds in bed. **On a multiplayer server a bed is only a respawn point**: nobody lies down and nobody can skip the shared night. Dying sends you back to the bed (if it is gone or boxed in you get the world spawn and a message). Breaking either half drops exactly one bed. The respawn point is saved with the player, also on the server. Limits: beds are red only (there are no dyes), and there is no Nether to explode them in.
- Building blocks (done): **stone bricks** (four stone), **slabs** and **stairs** in wood, cobblestone, stone, sandstone and stone brick (six blocks in a row make six slabs; the usual staircase shape makes four stairs), **wooden doors** (two wide, three high: three doors), **trapdoors**, **fences** and **fence gates**, **ladders** (seven sticks) and **glass panes** (six glass make sixteen). Slabs go in the half you click (the top half on a ceiling or when you click high on a wall) and two of one kind merge into the full block; stairs rise away from you and flip when placed on a ceiling; doors stand on the edge nearest you, hinged on your left with the handle on the far side, and open as a pair (toward the hinge side), trapdoors sit against the wall you click, gates close the way you look, fences and panes join up to each other and to solid blocks, and a ladder hangs on the side of a solid block (and pops off if it goes). Right-click a door, trapdoor or gate to open and close it (never on someone standing in it). They are real shapes for walking: you step up onto a slab or a stair without jumping, a fence or closed gate is 1.5 blocks tall so you cannot jump it, an open gate lets you through, and a ladder climbs with forward or jump (you climb out over the top onto the block it hangs on), holds with Shift, and a slide down it does no fall damage. The crosshair outlines the real shape, and you look through the gaps of a fence. Breaking a slab, stair, trapdoor, gate or ladder gives the one item whichever way up or open it is; half a door removes both and gives one door. Limits: stairs have no corner shapes, a full block made of two slabs drops one block, there are no iron doors or bars, signs, or pressure plates and buttons, and mobs do not open doors.
- Recipe book (done): the green book button beside the crafting grid (inventory and crafting table) opens a book that joins the inventory window, laid out like the original: icon tabs down the left edge (All, Tools, Building, Armor, Food, Misc), a search box, a crafting-table button that shows only what you can make now, five recipes to a row with pages, and a red frame on recipes you lack items for. As in the original, a recipe shows up once you have held one of its ingredients, so the list grows with your progress. A card 'New Recipes Unlocked! Check your recipe book' slides in at the top right when a find unlocks something (several at once share one card with a cycling icon); what you carry when a world opens is learned quietly. Pointing at a recipe shows its ingredients as ghosts in the grid; click to lay it out, shift-click to fill as many crafts as you can. The list is remembered per world on this device (browser storage), and creative mode lists everything.
- Drops (audited): every block gives something real with the right tool, and every item can be obtained in survival (a test proves it). Iron and gold ore now drop raw iron and raw gold (smelt them into ingots; the ore blocks themselves still smelt too). Gold ore needs an iron pickaxe, iron ore a stone one, diamond ore an iron one, as in the original; with too weak a tool the block breaks, drops nothing, and a hint says which tool is needed.
- Guest or wallet, then your character (done): before the world, the title screen asks who is playing. **Guest**: pick a name and a character and go; nothing is saved (no world, progress, recipe book or cloud copy is read or written on the device, and the server stores nothing for guests). **Solana wallet**: sign in, then your progress is saved as before (single-player worlds on the device and optionally in the cloud, the multiplayer realm on the server) and your name and character are saved on the account, so you look the same on every device. A wallet character is permanent: it is made once (the creator asks twice) and can never be edited or renamed, only deleted, and deleting it (type its name to confirm, not while it is in the realm) erases the whole character and all its progress (realm progress, cloud worlds, worlds on this device) and frees the name for a new character. The character creator has a live 3D preview with skin tone, hair style and colour, eyes, hoodie and trousers, and a Randomise button; names are 3 to 16 letters, digits, spaces and `_ . -`, and an account name is unique. A look is one small number (`lookCode` in `packages/shared/src/look.ts`) that the server stores (`POST /auth/character`, once; `POST /auth/character/delete` to wipe it) and sends to everyone, so other players see the character you made; the 64x64 skin pipeline is ready for custom skins later. Links such as `/play/Alice` or `/?seed=1` skip the title screen and keep working as before.
- Dyes (done): **sixteen dyes** and **fifteen coloured wools**. Red from a rose, yellow from a dandelion, black from an ink sac, three white from a bone, blue from **lapis lazuli** (the ore is found deep underground and mined with a stone pickaxe or better for four to eight lapis lazuli and some experience; one lapis grinds into one blue dye), green by smelting a cactus; the rest are mixes of two (red + yellow is orange, red + white pink, blue + white light blue, red + blue purple, green + blue cyan, purple + pink magenta, gray + white light gray, black + white gray, green + white lime, and, since there is no cocoa, red + green is brown). A wool and a dye in the crafting grid make wool of that colour, and wool of any colour can be dyed again. **Beds come in all sixteen colours**: three wool of one colour over three planks make a bed of that colour (plain wool is white, red wool is the red bed this game started with); it is placed, slept in and broken like before, and breaking either half gives back one bed of its colour. Sheep are born white (mostly), black, gray, light gray, brown or, rarely, pink; they drop wool of their own colour, and **right-clicking a sheep with a dye** recolours it (one dye used up) and the new colour shows at once for everyone and is saved. Limits: a bed cannot be re-dyed once made, there are no shears (a sheep is shorn by killing it), no bone meal for crops, and no dyed glass, banners or armour.
- Title screen and game modes (done): the plain address opens a fantasy-MMO style front page (a slideshow of screenshots from the game, the logo, one big **PLAY GAME** button, and sections on the game modes and features). PLAY GAME opens the play page (`#play`), where you choose **Single player** or **Multiplayer** (the online realm, with its status and a player name box), then in single player one of three modes: **Survival** (classic experience), **Creative** (unlimited building) and **Hardcore** (extreme difficulty), each with what you can do, its mechanics and who it is for. The chosen mode has New world and, when you have one, Continue; there is a seed box (a number, or any words, hashed) and a list of your worlds with Play and Delete. Hardcore is survival with one life on Hard difficulty (mobs hit 1.5 times as hard, hunger can kill, no switching to creative); dying ends the world, and you can only spectate it (fly through everything, invulnerable, no breaking or placing). A hardcore death is saved at once, so reloading cannot bring you back. Links with `?seed=`, `?online`, `?debug` and so on skip the title screen (`?home` brings it back). Hardcore is single-player only for now. The pictures on these pages are in `apps/web/public/shots`; `node scripts/shots.mjs` takes new ones from the running game (dev server on port 3000).
- Enchanting (done): three wheat make paper, paper and leather a book, six planks and three books a bookshelf; four obsidian, two diamonds and a book make an enchanting table. Up to fifteen bookshelves in the ring around it raise the offers: three choices, each with a level cost and a hint of one enchantment, paid in that many levels and lapis lazuli. Nineteen enchantments with real effects (Protection and its kinds, Feather Falling, Respiration, Sharpness, Knockback, Fire Aspect, Looting, Efficiency, Silk Touch, Unbreaking, Fortune, Power, Punch, Flame, Infinity, Mending), enchanted books (also found in dungeon, mineshaft and temple chests) and an anvil to mend a tool with its material, join two items and move a book's enchantments onto an item (more than 39 levels is too expensive, see the next entry). Enchanted items shimmer and list their enchantments in the tooltip. The table screen shows your level, and a red warning (or the tooltip on an offer) says when an item, lapis or levels are missing. Not built: the rarer enchantments (Thorns, Depth Strider...), librarians.
- Anvil, grindstone and table extras (done): the **anvil** has a name box (type a custom name for one level; it shows in italics, up to 35 characters) and every trip through it adds an invisible *prior work* penalty that doubles (1, 3, 7, 15, 31...) and is added to the next price, so after about six uses an item is **Too Expensive!** (creative is free and never refuses). Using an anvil wears it, about one use in eight: it looks **chipped**, then **damaged**, then breaks after roughly two dozen uses. An anvil with nothing under it **falls like sand** and hurts what it lands on (two points a block it fell, up to 40, players and mobs), and may chip on landing. The **grindstone** (a stone slab on two sticks, between two planks) takes every enchantment off an item for experience (the rarer, the more), clears its penalty, or joins two worn items of a kind; a lone enchanted book becomes a plain book. The enchanting table now floats a **book** above it that bobs, turns and flaps its covers, and each offer's clue is written in an **alien script** (hover for the plain-letter hint); **lapis lazuli** is a real item (lapis ore drops four to eight, a cleric sells it, one makes a blue dye; blue dye from an older save no longer enchants), your **enchantment seed is saved**, so offers stay the same across sessions until you enchant something, and a **Bottle o' Enchanting** (dungeon chests, level-five clerics) is thrown with right-click and bursts into three to eleven experience. Not built: the grindstone's second input keeping enchantments, anvil sound variants, enchant-table particles.
- Teleport, second world, TNT and farm tools (done): **ender pearls** (dropped by endermen, bought from villagers) are thrown with right-click and carry you to where they land, for five points of fall damage (none in creative). The **second world** is a flat 64 x 64 square of stone with a stone-brick border floating in the void (step off and you fall out of the world); it keeps its own blocks, player and clock apart from the overworld (a placeholder for a real second world to come). Press `/` and type `world square` or `world overworld` (creative mode only, single-player; `?world=square` in the address starts there). **TNT** (five gunpowder and four sand) is lit by flint and steel or by fire, burns a four-second fuse and blows a radius-4 crater, hurting you and mobs and setting off other TNT. **Shears** (two iron ingots) shear a sheep for one to three wool without killing it (the wool grows back in three minutes) and cut leaves, cobwebs and wool whole. **Bone meal** is the white dye: it ripens wheat, sometimes grows a sapling into a tree and sprouts tall grass and flowers on grass. **Breeding**: feed two cows or sheep wheat, pigs an apple, chickens or rabbits seeds; they walk to each other, a half-size baby appears (and some experience), it grows up in twenty minutes (food hurries it) and the parents rest five minutes. **Slime blocks** (nine slimeballs) stop any fall and bounce you back up unless you crouch. Not built: a portal to the second world.
- Rails, minecarts and boats (done): **rails** (six iron ingots and a stick make sixteen) lay themselves out as you place them: a line, a corner when a neighbour turns, a slope when the neighbour is a block higher, and they straighten again when a neighbour is broken. **Gold rails** (six gold ingots and a stick make six) are always live and push a moving cart on (they do not need redstone). A **minecart** (five iron ingots) is set on a rail with right-click; right-click it to climb in, push the forward key to get it rolling, look and crouch (Shift) to get out; slopes pull it, plain rails slow it, it stops where the track ends, and walking into an empty one shoves it. A **boat** (five planks) is launched on water, floats at the surface and steers towards where you look. Punch either to pick it up again. Carts and boats are saved with the world and shared with other players online.
- Redstone basics (done): **redstone ore** (deep, below layer 16; an iron pickaxe) drops four or five **dust**, which is laid on the ground like a rail and carries a signal of strength 15 that fades by one every block (it climbs a block and comes down again unless something solid sits over it). **Levers** (stick over cobblestone) and **stone buttons** (a stone; they pop out after a second) stick to the floor or a wall and are used with right-click, **pressure plates** (two stone or two planks; wooden ones also feel dropped items) are pressed by anything standing on them and rise a second after it leaves, a **block of redstone** (nine dust) is always on, and a **redstone torch** (dust over a stick) is lit unless the block it hangs on is powered (it flips one tenth of a second late, which makes clocks and memory, and burns out if it races). A powered source feeds the blocks beside it, strongly powers the block it is fixed to, and dust feeds the blocks it points at. **Redstone lamps** (four dust round glowstone) light up, doors, trapdoors and fence gates open and shut, and TNT is lit. Not built: pistons and repeaters.
- Fire (done): flint and steel (an iron ingot and a flint) lights a fire on a block face and wears down with each use. Fire behaves like the original's: it needs something to stand on or burn, spreads to nearby flammable blocks (planks, wool, logs, leaves, hay, bookshelves, grass...) and burns them away, dies out on bare ground, in rain and under water, and is put out by punching it. Standing in flames (or lava) sets you alight: you take damage while burning, flames fill the screen edge, water puts you out, Fire Protection shortens it, and dying that way says so. Mobs catch fire too (and drop cooked meat if they die burning) and dropped items burn up. Fire is animated and gives light. TNT is built (see the next entry). Not built: lava igniting wood, lightning or flaming arrows lighting fires, other players visibly burning.
- Tooltips and font (done): hovering an item shows a dark-purple tooltip in the original's style: name (aqua when enchanted), its kind (Equipment, Food, Block, Material...), its numbers (`+6 Attack Damage`, mining speed, armor and toughness, hunger restored, block hardness and best tool, fuel value), enchantments, and durability left (red when nearly broken). The whole game uses the Monocraft font (a blocky pixel look, SIL Open Font License, bundled in `apps/web/public/fonts/` with its license; no third-party game assets).
- Villages (done): roughly one in every 430 by 430 blocks (usually within a few hundred blocks of the spawn; F3 shows the nearest one with its distance and direction), on flat dry land in plains, forest, desert and snow biomes, there is a village: a roofed well in a stone-brick plaza, four gravel roads, and along them small and large houses built with the building blocks (a real door, glass panes, a roof of stairs and slabs, foundations and corner posts, a coloured bed, a table with chairs, fence-post porches, window boxes, a crafting table, torches, a furnace in the big ones), fenced wheat farms with a water channel and a gate, a stone-brick smithy with furnaces, market stalls with coloured wool awnings, a watchtower with a ladder and a lookout, and lamp posts. The look follows the land: oak, birch and cobblestone in plains and forests, spruce in the snow, sandstone with flat roofs in the desert. Generated from the seed like terrain, flattened to the village's ground level and blended into the hills around it, identical whichever chunk loads first. Houses hold a chest with village loot, and people live in them (next entry). The Nether and the End are not built.
- A richer world (done; the design and the comparison with the original are in [docs/WORLD.md](docs/WORLD.md)): winding caves, ravines and big halls that open onto the surface, with lava lakes deep down and flooded caves; rivers; sandstone under deserts, cacti and dead bushes; granite, diorite and andesite in the stone. Underground you find **dungeons** (a mossy room with a monster spawner that keeps making zombies or skeletons while you are near, and one or two chests) and **abandoned mineshafts** (timber-framed corridors with torches, side tunnels and supply chests). Chests in dungeons, mineshafts and villages hold loot rolled from the world seed the first time you open them (never refilled). Lava glows, slows you, burns you and mobs and destroys items; sand and gravel fall; cacti prick. Breaking a spawner gives experience but no item.
- Nature update (done; details in [docs/WORLD.md](docs/WORLD.md)): the world is now **256 blocks tall with sea level 63** (old saves still load). **Water and lava flow**: levels, waterfalls, infinite water from two sources, obsidian where water meets a lava source, cobblestone where it meets flowing lava, and **buckets** to scoop and pour. **Oak, birch and spruce** trees by biome (each with its own sapling), **lakes** on flat land (frozen in the snow), and **biome tint** for grass, leaves and water. Mineshafts get **rails, cobwebs and cave spider nests** (poison, never lethal); the desert has **temples** with a sealed chamber of four chests. **Twelve new creatures**: sheep, chickens, rabbits (three coats), squid, bats, spiders (they climb), cave spiders, slimes (they split), endermen (do not look at them), husks, strays and drowned, each spawning where it would in the original. Not built: minecarts and rails that carry anything, smoothed fluid surfaces, blended tint.
- Expansions (done as a plan and a title-screen showcase; the content is not built): SolRift grows in named chapters, like an MMO. The core game is live; **Embers of the Hollow King** (instances, dungeons and bosses underground) is in development, and **Tides of the Drowned Throne** and **Crown of the Sky Titans** are announced. The list is `packages/shared/src/expansions.ts`; the title screen shows each one with what it will add and marks anything unbuilt as "Not playable yet". See [docs/EXPANSIONS.md](docs/EXPANSIONS.md) for how to add one.
- Several characters (done): a signed-in wallet can make up to **three characters**. Each one is a separate save slot with its own class, progress, realm data, cloud worlds and worlds on this device; each is permanent and delete-only (type its name to confirm). The character step lists them (name and class) and offers a new one while there is a free slot (`POST /auth/character/select` switches, `POST /auth/character` creates, `POST /auth/character/delete` deletes the one in play). See [docs/ACCOUNTS_AND_SAVES.md](docs/ACCOUNTS_AND_SAVES.md).
- Classes (done): pick **Warrior**, **Mage** or **Ranger** when you make a character (after the name and look; a wallet character asks twice because the class is as permanent as the rest). Every class can still mine, build, craft and explore; the class changes how you fight.
  - **Stats** (`packages/shared/src/classes.ts`, one table, `computeStats(class, level, modifiers)`): max health (Warrior 28, Mage 14, Ranger 20), damage multipliers for melee, ranged and spell, damage taken, move speed, critical chance and damage, attack speed, and a resource pool with regeneration (Warrior **stamina**, Mage **mana**, Ranger **focus**). Everything grows a little with the class level (to 20). `StatModifier` is the hook for future gear, buffs and specializations.
  - **Abilities** (`packages/shared/src/abilities.ts`, a data table): Warrior: Ground Slam (leap high, and the shockwave where you land hurts, throws into the air and stuns, and shakes the screen), Shield Bash (stuns and throws back), Charge (flings what it runs into), Iron Defense (half damage); damage dealt and taken floats up as numbers; Mage: Fireball (bursts, sets alight), Frost Nova (damages and slows), Meteor (lands where you look after a delay), Arcane Shield (soaks 12 damage); Ranger: Piercing Shot (through everything in a line), Evasive Roll (a dash you cannot be hurt in), Bear Trap (roots and hurts), Rain of Arrows (volleys on an area). A new character knows none of them (keys Z, X, C, G): each is learned from its **skill book**, as in World of Warcraft (see below).
  - **Skill books** (`skillbooks.ts`, items 400 to 411, one per ability, a coloured book per class with a gold emblem): right-click the book, in your hand or in the inventory screen, to learn the ability; the book is used up (not in creative). Only the book's class can read it, and the character's class level must reach the ability's level (1, 1, 3 and 5 by button), otherwise the book stays in the bag and a message says why; a duplicate of a known ability is kept too. Where to get them: the weaponsmith Garrick (Warrior), the ranger quartermaster Fenna (Ranger) and the arcanist Lysa (Mage) each sell the four books of their class for 60 Auren per required level (sold back for a quarter); the first four quests (`welcome`, `first_timber`, `stone_age`, `night_watch`) each hand the character the book of its own class; and hostile monsters killed by a player may drop one (5 to 8 percent, 25 percent for an enderman), which can be the book of any of the twelve abilities (any class, whether or not the killer knows it, even if the killer has no class), with the higher-level books rarer. Leveling up only makes the books in your bag readable (a message tells which).
  - **Class level**: separate from the experience level. Kills give a hostile mob half its health in class points (animals 1), quest rewards add their experience, and each level raises health, damage and resource, and makes the next skill books readable. It is saved with the character.
  - **Weapons**: the Warrior starts with a stone sword and a shield; the Mage with a wand (right-click casts a bolt for mana); the Ranger with a bow, 32 arrows and a dagger. New craftable weapons fit the roles: greatsword, dagger, staff, wand, spellbook (bigger burst) and crossbow. Anyone may carry any of them; a class is just better with its own kind.
  - **Server authority**: a client sends only `{t:'ability', slot}`. The server checks the slot, that the ability has been learned, off cooldown and affordable, pays for it, runs it from its own state, and decides every hit, crit, stun and cooldown (timers run on the server's input steps). Other players see the effects (rings, bursts, a falling meteor, traps, shields) in their snapshots, and each player's class and class level next to their name. Abilities hurt hostile mobs only: players are never targets (PvP is off), and passive animals and villagers are left alone. Class mitigation (defense, Iron Defense, Arcane Shield, the roll) applies to every hit on a classed player.
  - **Saves**: `cls` in the player save holds `{id, lvl, xp, unlocked}` (no balances of any kind), so it lives wherever a character's progress lives (the device, the cloud, the realm database). The class itself is stored on the character record. A save without a class loads as before (classless play is the unmodified game).
  - **Not built**: skill trees, specializations (the hook is `ClassDef.specializations`; planned Warrior: Berserker, Paladin; Mage: Pyromancer, Frost Mage; Ranger: Assassin, Beastmaster), class-specific gear bonuses, PvP, and touch controls for movement (the ability buttons do work by touch).
